# Security

Please report suspected vulnerabilities privately using
[GitHub's vulnerability report form](https://github.com/TheeHappyCoder/lilt-charts/security/advisories/new).
Include the affected package version, impact, and a minimal reproduction using fictional data.
Do not include active credentials or customer data.

If the private report form is unavailable, open an issue titled **Private security contact
requested** with no vulnerability details, and a maintainer will help arrange a private
channel. Please wait for that channel before sharing the report.

Security fixes target the latest published version of `@lilt-ui/charts`. Older versions do
not have a separate maintenance branch. For ordinary bugs and feature requests, use issues.
